# intake/ (private, local only)

Drop project dossiers, PDFs, Word files, screenshots, and notes here. Start with `intake/inbox/` if you aren't sure where something belongs.

- **Not tracked by Git.** Everything here except this README and `_templates/` is ignored, so raw materials never reach GitHub.
- **Not part of the website.** The site only reads `content/` and `public/`.
- **Not backed up.** Keep your originals somewhere else too. In a Claude Code cloud session, files here disappear when the session's container is reclaimed.

Workflow: [docs/intake-workflow.md](../docs/intake-workflow.md)

Templates:
- `_templates/inventory.md`: the list of everything received
- `_templates/project-notes.md`: private working notes for one project (sources, evidence, conflicts, gaps, confidentiality)
