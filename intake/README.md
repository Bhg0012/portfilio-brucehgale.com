# intake/ (raw files, local only)

Drop project dossiers, PDFs, Word files, screenshots, and notes here. Start with `intake/inbox/` if you aren't sure where something belongs.

- **Not tracked by Git.** Everything here except this README is ignored, so raw files never reach GitHub.
- **Not part of the website.** The site only reads `content/` and `public/`.
- **Not backed up.** In a Claude Code cloud session, files here disappear when the session's container is reclaimed. That's why every upload is summarized, with its text extracted, in the tracked [`catalog/`](../catalog/README.md) folder. Keep your originals somewhere else too.
